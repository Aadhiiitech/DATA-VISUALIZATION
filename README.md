Real Estate Data Analysis
Project Overview:

This project analyzes house sales data using Python. It explores the dataset, creates new features, and identifies outliers in house prices and property sizes.
Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

Dataset: 
The project uses the kc_house_data.csv dataset containing house sales and property details.
Steps Performed
1. Loaded the dataset.
2. Checked the first and last rows, columns, data types, and summary statistics.
3. Checked missing values and duplicate records.
4. Created features such as sale year, property age, renovation status, and years since renovation.
5. Calculated price per living square foot and price per lot square foot.
6. Used boxplots to visualize outliers.
7. Identified outliers using the IQR method.
8. Saved the processed dataset as cleaned_real_estate.csv.

How to Run:
1. Open the notebook in Google Colab or run the Python script.
2. Upload kc_house_data.csv to the required location.
3. Run the code cells in order.

Output:
The project displays dataset summaries, feature calculations, boxplots, and outlier counts. It also creates a cleaned dataset file named cleaned_real_estate.csv.
